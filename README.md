# Week 7 Assignment: My Notes & The Report Builder

## Description

This assignment demonstrates Python file handling, reading and writing text files, working with CSV data, and handling missing files.

## Project Files

1. **my_notes.py** - Writes, appends, reads, and counts notes in a text file.
2. **my_notes.txt** - Stores the four notes generated by my_notes.py.
3. **report_builder.py** - Reads learner information from a CSV file and generates a report.
4. **hubs.csv** - Contains learner names, hub names, and scores.
5. **report.txt** - Contains the generated learner report.

## What happens if "a" is changed to "w"?

The "a" mode means append, which adds new information without deleting existing content.

If "a" is changed to "w", the existing content will be erased and replaced with the new information every time the file is opened in write mode.
